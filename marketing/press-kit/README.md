# Press kit

Everything a directory maintainer, journalist, or podcast host needs to describe Discerned
without asking.

| File | What it's for |
|---|---|
| `one-pager.md` | The full product summary — read top to bottom, no other context needed |
| `boilerplate.md` | The fixed "About Discerned" paragraph and link block, to paste verbatim |

Longer or differently-shaped copy lives in `../copy/` — `pitches.md` for five lengths of
elevator pitch, `feature-blurbs.md` for per-feature paragraphs.

---

## Visual assets — hosted, not duplicated here

**There are no image files in this folder, on purpose.** Every asset is stored once and served
from discerned.online, so a link in a third-party listing keeps working through repo renames,
branch renames, or a move off GitHub. This is the same rule that governs `../directories/` and
`../store-listing/`.

| Asset | URL | Source of truth |
|---|---|---|
| Screenshots (4, 1280×800) | `https://discerned.online/press/screenshot1.png` … `screenshot4.png` | `discerned-web/public/press/` |
| Icon (128px) | `https://discerned.online/icons/icon128.png` | generated by `pnpm gen:icons`, committed |
| Promo tile (440×280), marquees (1400×560) | not hosted — see `../store-listing/` | `../store-listing/*.png` |

**Do not add logo exports to this folder.** The icons are generated from SVG masters in
`discerned-ext/art/` and `discerned-web/app/icon.svg` by `pnpm gen:icons`; a hand-copied PNG
here would silently go stale the next time the art changes. If someone needs a specific size or
format, generate it from the master.

**Changing a screenshot** means replacing the file in `discerned-web/public/press/` — the URL
stays the same, so no listing needs resubmitting. Note that path is under `discerned-web/`, so
it does trigger a Netlify deploy, by design: the file has to ship to be served. Re-upload the
same image to the Web Store dashboard separately; the two are not linked.

---

## Usage by third parties

The screenshots, icon, and copy in this folder may be reproduced to write about or list
Discerned — directories, reviews, articles, roundups. No permission needed.

Two asks: use the hosted URLs above rather than re-hosting copies, so images stay current, and
don't present planned features (tipping, voting, mobile apps) as shipped. `../copy/claims.md`
records what is and isn't built.

The project is open source at `https://github.com/steveja42/discerned`, licensed
GPL-3.0-or-later. That licence covers the code; it doesn't restrict writing about the product.

---

## Accuracy

Everything in this folder traces to `../copy/claims.md`, which cites the source file behind each
claim. If something here contradicts the shipped product, the source files win — tell us at
`https://discerned.online/feedback` and it gets fixed.
