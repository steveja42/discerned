Pre-launch marketing and spec documents, kept for reference. **Every file here describes a
product that no longer exists.** Do not quote from them without checking the claim against
shipped code first.

| File | What it is | Why it's stale |
|---|---|---|
| `marketing.md` | The main pre-launch marketing doc | "WorthCast" brand; two-axis Interest + Ethics model; kind-9802 highlights |
| `copy-main.md` | Landing-page copy draft | Written against the two-axis model |
| `Brower Extension Implementation.md` | Developer spec + user flow | Two-axis evaluation UI, NIP-32 labelling, kind-10003 library index |
| `jungle.md` | Original concept doc | A Goodreads/Letterboxd review-bridge, before the general web capture tool |

**Since these were written:** the name is Discerned; evaluation is Signal + Qualifiers +
Category, not Interest + Ethics; nothing publishes kind 9802 (casts are kind 1, plus a
companion kind 30023 for long-form). NIP-44 encryption is still stubbed, so the "military-grade
encryption" claims are false.

Still worth mining for tone — "signal vs. noise" survived as the core hook, and several
pitches read well. See `../CLAUDE.md` for the current terminology rules.
