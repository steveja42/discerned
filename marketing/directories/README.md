## Maintenance notes

**Gallery and thumb URLs both point at `discerned.online`** — our own domain, so they survive
repo renames, branch renames, and a move off GitHub. The gallery images are the Chrome Web
Store screenshots, stored once at `discerned-web/public/press/` and served from there; they are
deliberately NOT duplicated under `marketing/`. `thumb` uses `icons/icon128.png`, generated by
`pnpm gen:icons` and committed.

The Web Store's own CDN links (`lh3.googleusercontent.com`) were used originally and should not
be reinstated: they are opaque, unversioned, and re-uploading a screenshot in the dashboard
mints a new URL, silently breaking the gallery.

**Changing a screenshot** means replacing the file in `discerned-web/public/press/` — the URL
stays the same, so no directory resubmission is needed. Note this lives under `discerned-web/`,
so such a change DOES trigger a Netlify deploy (by design: the file has to ship to be served).
Re-upload the same image to the Web Store dashboard separately; the two are not linked.

**Feature-list claims must match shipped behaviour.** See `../CLAUDE.md` for the terminology
rules. The two easiest to get wrong here: private clips are local-only and *not* encrypted
(NIP-44 is stubbed), and casting is capture-time only — a stored clip cannot be cast later, so
never phrase a feature as though it can.
